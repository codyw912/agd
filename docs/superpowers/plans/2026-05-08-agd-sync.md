# AGD Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `agd sync` so the managed agent workspace can fast-forward its default target branch from the human checkout without touching agent branches.

**Architecture:** Reuse project discovery and the system Git wrapper. Implement a focused `sync` module that loads the default workspace, refuses dirty human or agent checkouts, fetches the default target from the human checkout, verifies it is a fast-forward, updates only the workspace target branch, and leaves `agent/*` branches untouched.

**Tech Stack:** Rust, `clap`, system `git`, existing real-Git integration tests in `tests/p0a.rs`.

---

## File Structure

- `src/cli.rs`: add `Sync`.
- `src/main.rs`: dispatch `Sync` after AGD project discovery.
- `src/sync.rs`: implement dirty checks, fast-forward validation, and target ref update.
- `tests/p0a.rs`: add real-Git integration tests for fast-forward sync, agent branch preservation, non-fast-forward refusal, and dirty-state refusal.
